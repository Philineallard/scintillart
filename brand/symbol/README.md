The simplified S, taken from the website icon: Playfair Display Italic "S", 46 units tall in a 64-unit square, centred, outlined to vector so it does not depend on the font loading.

- `s-symbol-dark.svg` (carbon) and `s-symbol-light.svg` (ivory): transparent, 64 × 64 box.
- `s-symbol-website-icon.svg`: the website's icon exactly as built (`#27231F` S on `#E8DFCF`). That tile colour is not a brand colour (it is close to parchment); use it only to match the site.
- `s-symbol-tile-parchment.svg` / `.png` (512 px) and `s-symbol-tile-carbon.svg` / `.png`: the same S on brand parchment or carbon, for avatars, app icons and favicons.

Use the symbol when the full name becomes hard to read (small sizes, avatars). Do not use it beside the full wordmark, since both start with the same letter. Check minimum sizes in the final application.
