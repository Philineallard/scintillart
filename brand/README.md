# Scintillart brand pack (Guidelines v2.0, November 2026)

Start with `BRAND-BRIEF.md`: paste it into any AI assistant as the system prompt or first message.

- `guidelines/`: full brand guidelines as Markdown (`usage-rules.md` is the short rule set).
- `tokens/tokens.json`: colours (light and dark), type styles, spacing, radius, with usage notes. `tokens/tokens.css`: the same as CSS variables and `@font-face` (fonts are loaded from `../fonts`; switch themes with `data-theme="dark"`).
- `fonts/`: Playfair Display and Poppins as woff2 (SIL Open Font License).
- `logos/`: wordmark SVGs (dark and light) and the original raster artwork.
- `symbol/`: the S symbol from the website icon, transparent and tiled versions.
- `texture/`: the website's film grain tiles and the recipe.

Not included: descriptor lockups (to be confirmed), the four-point star motif (unapproved), the gold emblem (provisional). Still missing from the guidelines source: sections 13–21 (social, print, web rules).
